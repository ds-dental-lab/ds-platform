# 메일 템플릿

Supabase 가 보내는 인증 메일의 내용입니다.
**대시보드에만 두면 아무도 못 찾습니다.** 여기 두고, 고칠 때 여기를 고칩니다.

## 어디에 붙이나

Supabase → **Authentication → Emails** → 아래 표대로.
HTML 칸에 파일 내용을 통째로 붙여넣고 **제목(Subject)** 도 함께 바꿉니다.

| 파일 | 대시보드 항목 | 제목(Subject) |
|---|---|---|
| `recovery.html` | Reset Password | `덴플로우 비밀번호 재설정 인증번호입니다` |
| `confirmation.html` | Confirm signup | `덴플로우 가입 확인 메일입니다` |

나머지 항목(Magic Link · Invite user · Change Email)은 **우리가 안 씁니다.**
계정은 디자인센터가 사용자탭에서 직접 만들고(임시 비밀번호를 알려 주는
것이 곧 초대), 로그인은 비밀번호로 합니다.

## ★★ 비밀번호 재설정에는 `{{ .Token }}` 이 반드시 있어야 합니다

우리 비밀번호 찾기 화면은 **번호를 넣는 방식**입니다.
기본 템플릿은 링크만 보내서, 메일을 받고도 넣을 번호가 없었습니다
(2026-08-21 실제로 그 상태였습니다).

링크(`{{ .ConfirmationURL }}`)도 함께 둡니다 — 화면이 두 길을 다 받습니다.
`resetPasswordForEmail` 이 `redirectTo: /reset` 을 주고, 그 화면이
`PASSWORD_RECOVERY` 를 받아 비밀번호 칸으로 넘어갑니다.

## 만들 때 지킨 것

- **그림을 안 씁니다.** 메일 프로그램들이 SVG 를 지웁니다 — 로고는 글자로 그립니다.
- **표(table)로 짭니다.** flex·grid 는 메일에서 안 삽니다.
- **폭을 박지 않습니다.** `width="100%"` + `max-width:560px`.
  560 으로 박았더니 좁은 화면에서 잘렸습니다 — 메일은 휴대폰으로 더 봅니다.
- **인증번호 자릿수를 6으로 믿지 마세요.** 실제로 8자리로 온 적이 있고,
  자릿수는 Supabase 쪽 설정입니다. 제일 긴 경우(10자리)로 280px 화면에서
  재 보고 글자 크기(26px)·자간(4px)·옆여백(18px)을 정했습니다.
  6자리만 보고 정하면 8자리가 왔을 때 옆으로 넘칩니다.
- 색은 로고와 같습니다 (남색 `#16324F` · 청록 `#14B8A6` · 파랑 `#1279E8`).
