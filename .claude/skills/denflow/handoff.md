# 덴플로우 인계 메모 — 형식

대화형 Claude 에서 정한 것을 Claude Code(코드·기록)로 넘기는 블록입니다.
결정이 생기거나 코드에 할 일이 생긴 답의 **맨 끝**에 붙입니다. 결정이 없으면 붙이지 않습니다.

```
## 덴플로우 인계 (YYYY-MM-DD, 대화형)
- 주제: 한 줄 제목
- 결정: 사용자가 정한 것 (사용자 말 그대로 한 줄 인용이 있으면 좋음)
- 이유: 왜 그렇게 정했나
- 코드에 할 일: 화면 / 규칙 / 문구 — 없으면 "없음"
- 바뀌는 대외 문구: 치과가 읽게 될 글 전문 — 없으면 "없음"
- 확인 방법: 끝났는지 어떻게 보나
- 기록할 메모리: ds-flow-xxx (고침) 또는 새 이름 (새로)
- 근거로 본 기록: reference/…/ds-flow-xxx.md
```

규칙
- 날짜는 절대 날짜로 (YYYY-MM-DD). "내일·다음 주" 금지.
- 비밀번호·접속 코드·내려받기 번호 같은 비밀값은 넣지 않습니다.
- 대외 문구에는 '기공소'·'덴트버드' 이름이 들어가면 안 됩니다.
- 여러 결정이면 블록을 여러 개로 나눕니다 (하나에 하나).

예시
```
## 덴플로우 인계 (2026-10-20, 대화형)
- 주제: FlowTemp 영업 한 줄 소개
- 결정: "자체 개발한 자동 출력 시스템 FlowTemp — 크라운과 함께 주문하면 임시치아는 치과에서 바로 뽑습니다"
- 이유: 설계 방식은 사실대로, 덴트버드·기공소 이름은 빼기
- 코드에 할 일: 홈페이지 FlowTemp 소개 칸 문구 교체
- 바뀌는 대외 문구: (위 결정 문장 그대로)
- 확인 방법: denflow.kr 홈에서 문구 확인
- 기록할 메모리: ds-flow-fdm-print (고침)
- 근거로 본 기록: reference/06-현장-자동화/ds-flow-dentbird-terms.md
```
