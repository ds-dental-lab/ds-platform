**2026-08-12 결정.** *"회원가입창에서 유저가 디자인 가입 못하게 화면에서
없애줘"*, *"치과랑 기공사 회원 가입이 완료되면 디자인 센터가 승인을 해줘야
이용할수 잇게 해줘"*

전에는 **초대장 전용**이었습니다 — 디자인센터가 먼저 거래처를 만들고
초대장을 보내야 했습니다. 이제 치과·기공소가 **먼저 문을 두드릴 수**
있습니다. 다만 문을 여는 것은 여전히 디자인센터입니다.

규칙은 `domain/signup` (테스트 23개), 표는 `signup_requests`.

## ★ 디자인센터는 고를 수조차 없습니다

이 판은 디자인센터가 가운데 서서 치과와 기공소를 잇는 구조라
([[ds-flow-org-model]]), 아무나 디자인센터로 가입하면 **승인해 줄 사람이
자기 자신**이 되어 승인이라는 절차가 뜻을 잃습니다.

막는 곳이 셋입니다: 화면(선택지에 없음) · 가입 트리거(조용히 무시) ·
`signup_requests` 의 **check 제약**. 화면에서 지우는 것만으로는
주소로 직접 보내면 그만입니다.

## 흐름

1. 가입 → `handle_new_user` 가 신청서를 남깁니다.
   **DB 트리거가 하는 이유**: 가입 직후에는 세션이 없어(메일 확인)
   서버 액션을 부를 수 없습니다. 기관 정보는 `raw_user_meta_data` 로 옵니다
2. 승인 전에는 `memberships` 가 없습니다 → RLS 가 전부 가립니다.
   **화면을 따로 잠글 필요가 없습니다**
3. 대신 **왜 안 보이는지**는 말해 줍니다 (`/` 의 대기 화면).
   "소속된 조직이 없습니다" 만 띄우면 자기가 뭘 잘못했는지 찾다가 전화를 겁니다
4. 승인(`approve_signup`) → 조직 + 거래관계 + 관리자 자리가 **한 트랜잭션**.
   나눠 부르면 가운데서 끊겼을 때 조직만 남고 아무도 못 들어갑니다
5. 반려에는 **사유가 필수**입니다 — 본인에게 그대로 보입니다.
   이유 없이 반려하면 같은 내용으로 또 신청합니다

들어가는 길: **디자인센터 → 가입승인** (`/design/signups`, 관리자만)

## ★★ `my_org_type() <> 'design_center'` 은 문을 안 잠급니다

**소속이 없는 사람은 그 값이 null 입니다.** `null <> 'x'` 는 true 가 아니라
**null** 이라, `if` 가 그냥 지나갑니다.

실제로 잡혔습니다: 승인 대기 중인 가입자가 `approve_signup` 을 직접
불렀더니 권한 검사를 **지나쳐** 한참 안쪽 not-null 제약에서야 멈췄습니다.
우연히 막힌 것이지 막은 것이 아닙니다 — 그 열이 nullable 이었으면
조직이 생겼을 겁니다.

→ `is distinct from` 을 쓰고, role 은 `coalesce(my_role()::text,'')` 로 봅니다.
→ **같은 함정이 `create_partner_org` 에도 있었습니다** (먼저 만든 함수).
  함께 고쳤습니다 (`20260812201000_null_guard`).
→ **security definer 함수에서 `<>`·`not in` 을 쓸 때마다 이걸 의심하세요.**

관련: [[ds-flow-member-roles]] [[ds-flow-org-model]] [[ds-flow-backlog]]


## ★★ 가입 메일이 안 갑니다 — 기본 메일 서비스의 한도 (2026-08-21)

사장님: "회원가입하는데 메일이 안 오네…?"

찔러 보니 **`over_email_send_rate_limit` (429)** 였습니다.
Supabase 의 **기본(내장) 메일 서비스**는 **시험용**이고 시간당 몇 통뿐입니다.
운영에 쓰라고 만든 것이 아닙니다.

★ 가입만의 문제가 아닙니다. **비밀번호 찾기도 같은 메일을 씁니다.**
  거래처를 받기 시작하면 둘 다 안 됩니다.

★ 진단하다 알게 된 것 — **미확인 계정**(`hep789@gmail.com`)에 같은
  주소로 가입을 시도하면 GoTrue 가 **확인 메일을 다시 보냅니다**.
  그래서 실제로 한 통 나갔고(14:04), 그게 남은 할당량을 써서
  다음 시도가 429 로 떨어졌습니다.

★ **이미 확인된** 주소로 가입하면 오류 없이 200 이 옵니다(주소 캐내기
  방지). 화면은 "메일 보냈습니다" 라고 하는데 아무것도 안 갑니다 —
  메일 안 온다는 말의 또 다른 원인일 수 있습니다.

**할 일 (사장님 손)** — 커스텀 SMTP 를 붙여야 합니다.
Authentication → Emails → SMTP Settings. 도메인이 `denflow.kr` 이니
Resend·SES 같은 곳에 도메인을 확인시키고 그 값을 넣습니다.
★ SMTP 를 붙여야 Auth → Rate Limits 의 메일 한도도 올릴 수 있습니다.

**그동안의 임시 길** — 디자인센터가 사용자탭에서 계정을 직접 만들면
메일이 필요 없습니다(임시 비밀번호를 알려 주는 것이 곧 초대).

## 화면 문구를 고쳤습니다

전에는 `가입하지 못했습니다: email rate limit exceeded` 였습니다 —
치과 원장님이 보는 자리에 영어가 그대로 찍혔습니다.
`signupFailure(raw)` (domain/signup) 가 우리말로 갈라 줍니다.
메일 한도면 **무엇을 하면 되는지**까지 말합니다("잠시 뒤에 다시
하시거나 디자인센터로 연락 주시면 바로 열어 드립니다").

★ 시험이 "어떤 말이 와도 영어가 안 샌다" 를 봅니다
  (`not.toMatch(/[a-z]{4,}/)`). [[ds-flow-password-reset]] 도 같은 모양.


## SMTP 를 붙였습니다 — 메일이 나갑니다 (2026-08-21)

**Resend + 가비아 DNS.** denflow.kr 은 Vercel 이 아니라 **가비아**에서
DNS 를 관리합니다 (NS: `ns.gabia.co.kr` · `ns1.gabia.co.kr` · `ns.gabia.net`).
홈페이지만 Vercel 을 가리킵니다(A `216.198.79.1`).

넣은 레코드 셋 (My가비아 → 도메인 → DNS 관리 → DNS 설정)
- MX  `send` → `feedback-smtp.ap-northeast-1.amazonses.com.` 우선순위 10
- TXT `send` → `v=spf1 include:amazonses.com ~all`
- TXT `resend._domainkey` → `p=MIGfMA0…ZQIDAQAB` (218자)

★ 가비아 함정 둘 —
  ① 호스트 칸에는 **`denflow.kr` 을 뗀 앞부분만** 넣습니다(`send`).
  ② **MX·CNAME 값은 점(.)으로 끝나야** 합니다. 안 그러면 저장이 거절됩니다.
  ③ 줄마다 '확인' 을 누른 뒤 오른쪽 아래 **'저장'** 까지 눌러야 반영됩니다.

Supabase SMTP 설정값
`smtp.resend.com` : 465 / Username **`resend`**(글자 그대로) /
Password 는 Resend API 키(`re_…`, 권한 Sending access, 도메인 denflow.kr) /
Sender `noreply@denflow.kr` · 이름 `덴플로우`
★ **Minimum interval per user 를 30초로.** 우리 재발송 버튼이 정확히
  60초에 열리는데(`RESEND_COOLDOWN`), 양쪽이 60이면 경계에서 튕깁니다.
★ SMTP 를 붙이면 메일 한도가 시간당 **30통**이 됩니다(더 올릴 수 있음).

**확인** — 아까 429 로 떨어지던 그 자리가 200, 계정 생성 ✓,
`confirmation_sent_at` 찍힘 ✓, 응답에 3.3초(실제 SMTP 왕복) ✓.

## 끝까지 눌러 확인했습니다 (2026-08-21)

가입 → 메일 → 비밀번호 찾기까지 **실제로 도착하는 것을 확인**했습니다.
보낸사람 `"덴플로우" <noreply@denflow.kr>`, 우리말 제목, 인증번호 실림.

**그 과정에서 고친 화면 문구 셋** — 셋 다 "영어가 그대로 새거나,
화면이 없는 일을 있다고 말하던" 것들입니다.
- `signupFailure()` — `email rate limit exceeded` 가 그대로 찍히던 자리
- `looksAlreadyRegistered()` — 이미 있는 주소인데 "메일 보냈습니다"
- `passwordSaveFailure()` — 무엇이든 "처음부터 다시" ([[ds-flow-password-reset]])

★ 시험은 셋 다 "**어떤 말이 와도 영어가 안 샌다**" 를 봅니다
  (`not.toMatch(/[a-z]{4,}/)`). 새 문구를 넣을 때 이 규칙을 지키세요.
