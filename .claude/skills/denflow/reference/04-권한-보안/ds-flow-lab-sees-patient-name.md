**2026-08-11 결정.** 설계서 §8.5(기공소에 환자 실명 차단)를 이 부분만 뒤집었습니다.

사용자 말 — *"기공소는 환자명을 봐야해... 그래야 치과에 정상 배송하지"*

기공소는 완성품을 치과로 보낼 때 **환자 이름으로 케이스를 구분**합니다.
이름을 가리면 어느 봉투가 누구 것인지 알 수 없습니다.

**실명 차단은 '배정받은 주문만'이 대신합니다.**
`orders` 의 select 정책이 `lab_org_id = my_org_id()` 로 잠가 두어,
기공소는 디자인센터가 나눠 준 건만 봅니다.
확인: 전체 12건 중 기공소가 보는 것은 4건.

**바뀐 곳** — `patientLabelColumn()` 은 늘 `patient_label` 을 돌려줍니다.
`domain/notification` 도 받는 쪽을 안 따지고 한 본문을 씁니다.
회귀 테스트는 "실명이 있어야 한다"로 뒤집혀 있습니다.

`patient_label_masked` 컬럼과 그것을 채우는 코드는 **지우지 않았습니다** —
다시 가려야 하면 읽는 쪽만 바꾸면 됩니다.

**⚠️ 아직 남은 구멍** — 주문별 대화(`order_messages`)는 기공소도 읽습니다.
치과가 본문에 실명을 적으면 그대로 보입니다. 자유 입력이라 코드로는 못 막고,
지금은 입력칸 아래에 "치과 · 디자인센터 · 배정된 기공소가 함께 봅니다"만 띄워 둡니다.
더 막으려면 글마다 '기공소에게 안 보이기' 토글을 다는 방법이 있습니다.

**⚠️ 감사 로그가 없습니다** — 설계서 §3.5 가 요구하는 `audit_logs` 가 아직 없습니다.
실명을 연 만큼 "누가 언제 무엇을 봤나"가 전보다 중요해졌습니다.

# 2026-08-20 — 이름은 보되, **스캔 원본은 못 받습니다**

*"기공소 계정은 스캔 데이터를 다운받을 수 없어야 해. 기공소는 쉐이드
파일만 봐야 하고 스캔 파일을 열어 봐서는 안 된다"*

기공소가 받는 것은 **센터가 만든 설계**입니다. 구강스캔 원본은 센터가
설계하는 재료이지 기공소가 볼 것이 아닙니다.

```
기공소가 여는 것   디자인 파일(확장자 무관) · 쉐이드 사진(png·jpg…)
기공소가 못 여는 것 스캔 칸의 3D — dxd·obj·stl·ply, 그리고 모르는 것 전부
```

## ★★ **막을 것을 세지 않고 열 것만 셉니다**

`.dxd .obj .stl .ply` 를 목록으로 막으면 새 스캐너가 `.3oxz` 를 뱉는 날
그대로 새어 나갑니다. 기공소에게는 **사진만** 엽니다
(png·jpg·jpeg·webp·gif·bmp·heic·heif). 모르는 확장자는 전부 닫힙니다.

★ heic·heif 를 빼면 안 됩니다 — 원장님이 아이폰으로 찍어 보냅니다.

★ **디자인 파일은 확장자를 안 따집니다.** 센터가 주라고 올린 것이고,
  거기 stl 이 들어 있는 것이 정상입니다.

★ **보는 사람의 소속(sector)으로** 가릅니다. 주문의 '역할' 로 가르면
  자사 제작에서 센터가 자기 주문의 스캔을 못 봅니다(통합 모델).

## ★★★ 문이 셋 필요했고, 셋째가 구멍이었습니다

```
① 목록        화면에서 자물쇠 표시 (감추지 않음)
② 서버 액션    서명 주소를 만들기 전에 막음
③ 저장소 정책  ← 이게 없으면 앞의 둘이 다 소용없습니다
```

저장소 읽기 정책이 *"이 주문의 당사자인가"* 만 봤습니다. 그래서 기공소
계정이 **우리 화면을 안 거치고 저장소 API 를 직접 불러 서명 주소를
스스로 만들 수 있었습니다.** `can_read_order_file()` 로 좁혔습니다.

★ 표에 없는 덩어리는 기공소에게 **닫습니다**(coalesce false).

★ **목록에서 감추지 않고 자물쇠**를 채웁니다. 아예 안 보이면 기공소가
  "치과가 파일을 안 보냈나?" 하고 전화합니다.

★ '전체 받기' 에서도 뺍니다. 목록만 고치면 거기로 새어 나갑니다.

★ 막힌 내려받기도 열람 기록에 남깁니다(`file.blocked`). 기공소가 스캔을
  자꾸 누르면 설계 파일이 아직 안 올라갔다는 신호일 수 있습니다.

★ 확장자 목록이 **코드와 DB 두 곳**에 있습니다. 어긋나면 시험이 잡습니다
  (`tests/domain/file-access.test.ts` 가 마이그레이션 파일을 읽어 대조).

확인 (운영·진짜 JWT) — 기공소: 스캔 stl·obj 막힘 / 쉐이드 png 열림 /
설계 stl 열림. 센터: 넷 다 열림. 저장소를 직접 찔러도 400.
