**새 프린터 표준 순서 (사용자 2026-10-27 "매번 새로 온 프린트는 어떻게 처리하나")**

A. 회사 검수 (받은 날, ~1시간)
1. 펌웨어 판 확인 — 01.03 그대로 / 01.04+ 는 LAN Only 뒤 Developer Mode (아직 안 겪음, 처음이면 같이)
2. 자동 업데이트 끄기
3. 회사 와이파이 → LAN Only
4. 캘리브레이션 전부 (회사 자리)
5. 필라멘트 로드 → 노즐에서 나오는지 확인 (안 넣어도 프린터가 출력 시작함)
6. 이 PC 에이전트: 프린터 찾기 → 액세스 코드 → 자동 출력 켜기
7. 다시 뽑기로 크라운 1개 끝까지 → 첫 층·기록 확인 (검수)
8. 이 PC 에이전트 자동 출력 끄기
9. 시리얼 + "덴플로우 소유" 라벨 (소유권은 덴플로우)
10. 설치 상자: 전원선·튜브 클립 4.0·건조기·인증 필라멘트·작은 공유기·예비 핫엔드·USB(최신 에이전트)·위생사 안내

B. 치과 설치 (~30~40분)
1. 최종 자리에 놓기 (앉는 자리에서 떨어진, 환기되는 곳)
2. 치과 와이파이 2.4GHz, 스캐너 PC 와 같은 망 (안 되면 공유기 AP 모드)
3. **캘리브레이션 전부 다시** (자리 바뀌면 첫 층이 너무 세게 붙음 — 2026-10-27 실측)
4. 건조기·필라멘트·튜브 클립, 로드 확인
5. 치과 PC 에이전트: 설치 → 연결 코드 → 감시 폴더 → 프린터 찾기(방화벽 허용) → 액세스 코드 → 자동 출력 → 설치 점검 두 번
6. 원장 스캔으로 끝까지 한 번
7. 위생사 10분: 식혀서 떼기, 필라멘트 갈기, 끊기면 다시 뽑기, 안 떨어지면 딱풀(이형제)

원칙: 액세스 코드는 치과 PC 에만(사진·메모 금지) · 회사 검수 출력(7) 빼먹지 않기.
