**2026-08-11 확정.** 보철 종류·재료가 코드(`PROSTHESIS_TYPES`)에서 표로 옮겨졌습니다.
제품을 하나 늘리려고 배포하던 것을 없앴습니다.

```
prosthesis_types      종류 — 이름·약칭·색·표시순서·판매상태
                           needs_implant_model · abbr_material_only
prosthesis_materials  재료 — 종류 아래. 이름·약칭·표시순서·판매상태
                           has_shade · has_pontic · has_pink
                           price · pontic_price · pink_price
```

- **'제품' = (종류 × 재료) 짝**입니다. 제품탭 표의 한 줄이 그것입니다.
- **성질이 제품에 붙습니다.** 전에는 종류로 코드에 박혀 있었는데,
  '커스텀 어버트먼트'는 임플란트인데 쉐이드도 폰틱도 없습니다 —
  같은 종류 안에서도 달라 종류로는 표현할 수 없었습니다.
  `isBridgeable` · `allowsGingival` · `requiresShade` 가 제품에 물어봅니다.
- **종류도 자기 규칙을 듭니다.** 덴쳐·교정을 추가할 수 있어야 해서
  '모델 필수'와 '재료 이름만 약칭', 색을 종류에 실었습니다.
  이제 `domain/prosthesis` 에 종류 코드로 판정하는 곳이 하나도 없습니다.
- **`code` 는 이름에서 자동 생성, 그 뒤 불변.** `order_items` 가 가리킵니다.
  수정 창에서 종류 이동도 막았습니다 — 같은 이유로 짝이 끊깁니다.
- **삭제 버튼을 두지 않습니다.** 판매상태로 내립니다.
  치과 목록에서만 빠지고 지난 주문은 그대로입니다.
- **`-` 와 `0` 은 다릅니다.** 못 쓰면 NULL(`-`), 쓸 수 있는데 무료면 `0`.
- 치은포셀린 금액(`surcharge_prices`)은 제품의 `pink_price` 로 흡수하고
  테이블·편집기·액션을 지웠습니다.

**단가 예외** — 제품 기본가를 덮어씁니다. 화면은 아직 없습니다.
- `clinic_product_prices` — 치과별 판매가 (사용자탭 > 치과)
- `lab_product_costs` — 기공소별 기공원가 (사용자탭 > 기공소). 치과엔 안 보임

**⚠️ 덴쳐·교정을 실제로 팔 때 다시 볼 것** — 지금은 '치아 하나 = 항목 하나'입니다.
총의치·교정은 악(顎) 단위라 치식을 14개 찍으면 값이 14배가 됩니다.
종류에 '치식 단위 / 악 단위' 플래그를 두는 길이 있으나 주문등록이 두 갈래가 됩니다.
