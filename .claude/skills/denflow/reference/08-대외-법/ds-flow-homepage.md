## `/` 가 세 얼굴을 합니다

```
로그인 안 함  →  회사 홈페이지
소속 있음     →  제 섹터로
승인 대기     →  그 사정을 알려 주는 화면
```

**주소를 둘로 안 나눴습니다.** 홈페이지와 플랫폼이 따로 있으면 거래처가
어디로 들어가야 하는지 헷갈립니다.

## ★ 참고 사이트에서 배운 것 — 핵심은 폼입니다

첫 초안에는 전화번호만 있었습니다. 그 사이트를 보고 알았습니다 —
**수가표 요청 폼**이 전환 장치입니다. 보고 마음이 동한 사람이 전화를
걸까 말까 망설이는 그 순간에 이름과 연락처만 남기고 갈 수 있어야 합니다.

받은 문의: **디자인센터 → 수가표 요청** (`/design/contacts`, 사이드바 배지).
전화번호를 누르면 바로 걸립니다.

- 넣기는 anon 도 되지만 **읽기는 디자인센터만** 됩니다 (RLS 로 확인함:
  anon 0건 · 치과 0건 · 디자인센터 1건)
- **동의 없이는 못 보냅니다** — 화면과 표 제약 이중으로
- 지우지 않고 '처리함' 으로 옮깁니다. 언제 연락했는지가 남아야 합니다

## ★ 베끼지 않은 것

그 회사 실적(누적 케이스 수·전직원 자격·수료증)은 **그쪽 것**입니다.
우리는 **모델리스**와 **자체 플랫폼**으로 씁니다 — 둘 다 사실입니다.
지어낸 숫자("20년 경력 · 정확도 99%")는 한 줄도 안 넣었습니다.
확인할 수 없는 것을 적어 두면 물어보면 곤란해집니다.

★ 그 회사 **이용약관은 반면교사**입니다. 제3조 제목은 '이용약관의 효력'
  인데 내용은 개인정보 권리이고, 제9~14조는 문자발송 서비스 조항이며,
  '충전 잔여금액 20% 환급' 이 남아 있습니다. 다른 약관을 가져와 다
  지우지 못한 문서입니다 — 베끼면 결함까지 물려받습니다.
  대조표: `docs/DS-Flow-처리방침-참고대조.md`

# 2026-08-18~20 — 이름·로고·약속 절·스크롤

## 이름이 두 번 바뀌었습니다

`DS 덴탈랩` → `덴플로우 치과기공소` → **`덴플로우 디지털 기공소`**.
검색 이름·서류·화면이 한 이름입니다. 한때 검색만 다르게 뒀다가
**하나로 합쳤습니다** — 이름이 둘이면 구조화 데이터로 묶어 줘야 하고,
명함·세금계산서·플레이스가 늘 때마다 "어느 쪽이었지" 가 따라붙습니다.

로고 글자는 **`DenFlow`**. 한 줄 소개는 **`디지털 기공소`**.

## 「덴플로우의 4가지 약속」 절 (지르카 시안)

어두운 남색 띠 + 흰 카드 넷. 제목 위 · 그림 가운데 · **걱정 한 줄 → 답
한 줄** 아래. 카드 한 장이 한 호흡에 읽혀야 해서 문장을 안 넣었습니다.

```
스캐너 무관        장비 바꾸실 필요 없이 / 쓰시던 그대로, 파일만
실시간 진행상황 공유  굳이 물어보지 않으셔도 / 접수 → 배송 화면에서 바로
모델리스 전 품목     크라운·브릿지, 인레이·온레이 / 임플란트 보철까지 모델 없이
리메이크 통계 & 분석  원인 모르고 넘어가지 않게 / 매달 모아 분석하고 고칩니다
```

★ 넷이면 큰 화면에서 한 줄에 떨어집니다. 다섯은 3+2 로 갈라집니다.
★ 제목이 두 줄 되는 카드가 있어 **모든 제목이 두 줄 자리**를 차지합니다 —
  안 그러면 그 카드의 그림만 아래로 밀려 눈높이가 어긋납니다.
★ 색은 시안의 초록이 아니라 **우리 로고 색**(남색 몸통·청록 꼬리).
★ *'전화 마세요'* 는 손님을 나무라는 투라 *'굳이 물어보지 않으셔도'* 로.

## 스크롤하면 올라오는 효과

절 머리글·첫 화면·카드가 24px 올라오며 나타납니다. 관찰자 하나로 다 보고,
한 번 나타나면 되돌아가지 않습니다.

★★ **`<html>` 을 건드리면 안 됩니다.** 감추는 CSS 를 켜려고 인라인
  스크립트로 `<html>` 에 표시를 달았다가 **수화가 깨져 첫 화면이 안 보인
  채 멈췄습니다.** class 든 data 속성이든 똑같이 깨집니다.
  → CSS 의 `@media (scripting: enabled)` 가 그 문을 대신합니다.

★ 안전장치는 **'관찰자가 한 번도 안 불렸을 때만'** 열어야 합니다.
  시간만 보고 열면 첫 화면을 몇 초 보는 사이에 아래가 다 나타나
  **효과가 사라집니다.**
