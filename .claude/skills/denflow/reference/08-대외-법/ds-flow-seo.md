**2026-08-15.** *"네이버 검색하면 나오게 하고싶어"* → 구글까지.
시작할 때 `robots.txt`·`sitemap.xml` 이 **둘 다 404** 였고 제목은
`DenFlow` 한 단어였습니다.

## 만든 것

```
app/robots.ts        플랫폼 차단 + Yeti(네이버) 규칙
app/sitemap.ts       / · /signup · /privacy 셋
app/opengraph-image  1200x630 PNG (그려서 만듦)
domain/site          주소·제목·설명·소유확인 코드 한 곳에
```

제목 `DS 덴탈랩 · 모델리스 전문 기공소`.
`DenFlow` 는 **그 이름을 이미 아는 사람만** 찾을 수 있는 제목이었습니다.

## ★★ robots.txt 가 개인정보 문제이기도 합니다

홈페이지와 플랫폼이 **한 주소**에 있습니다. `/clinic` `/design` `/lab`
아래로는 환자 이름·차트번호가 오갑니다. 로그인해야 열리니 내용은 안
읽히지만 **주소 자체는 검색 결과에 남을 수 있습니다** — 어디선가 링크가
걸리면요. 주문 주소가 검색에 뜨는 것만으로 거래처가 놀랍니다.

## 등록 상태

| | |
|---|---|
| 네이버 소유확인 | 완료 · 사이트맵 제출 완료 |
| 구글 소유확인 | 코드 넣고 배포까지 (누르셨는지는 못 봄) |

코드는 `domain/site` 의 `NAVER_VERIFICATION` · `GOOGLE_VERIFICATION`.
비어 있으면 태그가 아예 안 붙습니다 — 빈 태그는 확인을 실패시킵니다.

## ★ 네이버에서 데인 것 둘

**① `http://` 로 등록되어 있었습니다.** 네이버는 http 와 https 를 **다른
사이트**로 봅니다. 우리 사이트맵 주소가 전부 https 라 프로토콜이
어긋나서 뭘 넣어도 *"해당 도메인의 URL을 입력해주세요"* 로 막혔습니다.
→ 지우고 `https://denflow.kr` 로 다시 등록해서 풀렸습니다.
★ 등록칸에 `denflow.kr` 만 치면 네이버가 기본으로 `http://` 를 붙입니다.

**② 입력칸이 접두어 + 나머지 구조입니다.** 화면에 `https://denflow.kr/`
가 이미 박혀 있어서, 전체 주소를 넣으면 두 번 겹칩니다.
사이트맵 칸에는 **`sitemap.xml` 만**.

★ 옛 `http://` 사이트를 조회하면 *"robots.txt 가 존재하지 않습니다"* 가
  뜹니다 — 308 로 넘기는데 네이버 검사기가 안 따라가서입니다. 그 사이트를
  지우면 됩니다.

## ★ 솔직한 한계

네이버는 자체 콘텐츠(플레이스·블로그·카페)를 훨씬 위에 올립니다.
외부 홈페이지는 "웹사이트" 영역에 작게 걸리고 반영에 **1~3주**.

치과가 기공소를 찾을 때 **실제로 닿는 것은 네이버 플레이스**이고,
그건 **사업자등록이 있어야 합니다** — 처리방침 시행·카카오 알림톡과
같은 벽입니다 ([[ds-flow-backlog]]).

**구글이 먼저, 더 크게 보일 겁니다** — 자체 콘텐츠 편향이 없어서
홈페이지가 제값을 받습니다. 반영도 며칠.

## 앞으로 챙길 것

★ 홈페이지 글을 고치면 `app/sitemap.ts` 의 `HOME_UPDATED` 날짜도
  같이 올려야 합니다. `new Date()` 로 두지 않은 이유 — 부를 때마다
  "방금 바뀌었다" 고 말하면 검색엔진이 그 값을 안 믿습니다.

# 2026-08-18~20 — 이름을 바꾸고 로고를 물렸습니다

검색에 `DS덴탈랩 · 모델리스 전문 기공소` 로 뜨고 로고 자리가 비어
있었습니다. 이름을 **덴플로우 디지털 기공소** 로 바꾸고 로고를 물렸습니다.

## 로고

`SiteJsonLd` 가 `@graph` 로 **Organization + WebSite** 를 함께 냅니다.
Organization 의 `logo` 는 문자열이 아니라 **ImageObject(512×512)** —
크기를 같이 줘야 구글이 덜 까다롭습니다. 실제 `/logo.png` 도 512 정사각.
JSON-LD 는 **로그아웃 상태 홈페이지에서만** 냅니다.

★ 로고는 붙였다고 바로 안 나옵니다. 구글은 재수집 후 며칠~몇 주.

## ★ 제목에 꼬리표를 안 붙입니다

`덴플로우 · 모델리스 전문 기공소` 처럼 구분자 뒤에 설명을 달면 검색 결과가
그 문장째로 나옵니다. **제목 = 이름 하나.** 설명은 description 으로.

★ 시험 규칙을 *"제목에 한 줄 소개가 없다"* 로 썼다가, 한 줄 소개가
  이름의 일부(`디지털 기공소`)가 되면서 깨졌습니다. 지금 규칙은
  **"구분자(· | - : –) 뒤에 꼬리표가 없다"** 입니다. 규칙은 금지할 모양을
  적어야지 금지할 단어를 적으면 안 됩니다.

## ★★ 홈페이지와 /signup 의 제목·설명이 똑같았습니다

그래서 **네이버가 /signup 을 대표 결과로 올렸습니다.** 로그인 벽이 검색
결과가 된 셈입니다. `(auth)/signup/layout.tsx` 에 따로 metadata 를 줘서
갈랐습니다. → **로그인 안쪽 화면은 제목을 반드시 다르게.**

## 폐업한 동명 업체 (사장님이 하실 일)

네이버 플레이스 → 해당 업체 → **정보 수정 제안 → 폐업**.
구글은 비즈니스 프로필 → **비즈니스 닫기 제안**. 우리 코드로는 못 합니다.

## 아직 안 끝난 것

네이버 서치어드바이저 **사이트맵 제출(`sitemap.xml`)** 과
**웹페이지 수집(`/`)**. 구글 서치콘솔 **URL 검사 → 색인 생성 요청**.

★ 네이버 웹페이지 수집 칸은 **비워 두면 거절**합니다
  (`올바른 URL 형식으로 입력해주세요`). 홈페이지는 **`/` 한 글자**를 넣습니다.
