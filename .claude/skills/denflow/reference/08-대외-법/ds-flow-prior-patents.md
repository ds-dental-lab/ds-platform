사용자의 전 직장(이름은 적지 않음)은 FlowTemp 와 같은 "스캔→자동 설계→치과 프린터 원격 출력" 을 먼저 사업화했고 특허가 있다 (2026-10-21 확인, 구글 특허 기준·법률 자문 아님).

| 번호 | 내용 | 만료 | DenFlow 와 다른 점 |
|---|---|---|---|
| KR102227252B1 (2019 출원) | 보철 치료 통합 관리 서버: 치과 PC 에서 스캔+환자정보 받음 → 서버가 보철 CAD → 3D 프린팅 데이터를 치과 PC 로 → 치과 프린터로 임시보철 → **치과가 여러 기공소 중 하나를 고르면** 서버가 최종 보철 주문 | 2039-03 | **가장 가까움.** 다른 점: DenFlow 는 치과에 기공소 목록을 **절대 안 보여 줌**(기공소는 대외 비밀, 센터가 배정) — 청구항의 "여러 기공소 정보 전송 + 치과의 선택 수신" 요소가 없음. CAD 는 외부 서비스가 함 |
| KR102496189B1 (2022) | 쉘 타입 임시 크라운 자동 제조: **프렙 전** 스캔에서 AI 치아 분리 → 쉘 설계 → 프린터 | 2042-08 | FlowTemp 는 프렙 후 스캔으로 설계. 쉘 방식 아님. 분리 AI 없음 |
| KR102722969B1 (2024) | 구강 스캔에서 치아 자동 분리 알고리즘 | 2044-01 | 우리는 분리를 안 함(외부 설계 서비스 몫) |

- 셋 다 2026-03-19 신용보증기금(광주)의 **가압류** 등록 — 회사 사정이 어렵다는 신호. 특허가 제3자에게 넘어갈 수도 있음.
- 그 외 특허: 3D 오버프린팅 장치/방법 여러 건, 변색 필라멘트, 틀니 제조, 마스크. FlowTemp 와 무관.

**How to apply:** FlowTemp 를 치과에 열기 전에 **변리사 침해 검토 1회**(KR102227252B1 중심). 설계상 "치과가 기공소를 고르는" 기능은 앞으로도 넣지 말 것 — 비밀 정책과도 맞고 청구항 회피 요소. 전 직장 자료·코드는 하나도 가져오지 않았고 저장소 깃 기록이 독자 개발 날짜를 증명함. 영업은 전 직장 계약 거래처(스캐너 5년 계약 치과)를 피하고, 그런 치과에는 크라운 묶음 대신 임시치아 유료 서비스만. 관련: [[ds-flow-fdm-print]], [[ds-flow-lab-secret]], [[ds-flow-dentbird-terms]]
