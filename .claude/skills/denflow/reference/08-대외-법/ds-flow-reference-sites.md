홈페이지를 고칠 때 열어 볼 곳들. **주소만 적어 두면 안 열어 보게 되므로**
무엇이 재료인지 같이 적습니다.

## zircarlab.com — 지르카 디지털 기공소 (2026-08-14, 사용자가 알려 줌)

서울 금천구. 우리와 **같은 영역**입니다 — 서비스 목록에 '모델리스 보철
문제 해결' 이 있습니다.

★ **서비스를 기능이 아니라 '치과에게 무엇인지' 로 이름 지었습니다.**
  가져올 만한 것 중 제일 큽니다.

```
매출 성장의 핵심 : 2일 배송      ← '납기 2일' 이 아님
지그 시스템
모델리스 보철 문제 해결
통합 관리 플랫폼 : 지르카넷
보철물 분석 리포트
구강 스캐너 정밀 진단 서비스
구강 스캐너 도입
```

우리는 *"모델리스 전문 기공소"* 라고 **우리 관점**으로 적었습니다.
저쪽은 전부 **치과가 얻는 것**으로 적었습니다.

★ **플랫폼에 따로 이름을 붙였습니다** — `지르카넷`. 홈페이지 상단에
  '지르카넷 바로가기' 가 있습니다. 우리는 한 주소에 다 담기로 했는데
  ([[ds-flow-deploy]]), 이름을 나누는 쪽도 있다는 재료입니다.
  로그인·마이페이지·게시물 알림·공지 알림까지 붙어 있습니다.

★ **고객 후기 페이지(`/customer`)가 있습니다.** 우리에게 없는 것이고,
  사업자등록·실적이 쌓이면 만들 수 있는 자리입니다.
  블로그(`/article`)·뉴스(`/news`)도 따로 있습니다.

★ 전환 장치가 **'상담 신청'** 입니다. 우리는 '수가표 요청' 입니다
  ([[ds-flow-homepage]]). 무엇을 미끼로 걸지가 다릅니다 — 수가표 쪽이
  더 구체적이라 우리 선택이 나쁘지 않아 보이지만, 둘 다 두는 것도 됩니다.

### ★ 반면교사 — 내용이 전부 그림입니다

```
본문 글자수  219자
이미지       31개 (그중 alt 없는 것 26개)
큰 이미지    1920x461, 1121x1117, 800x800 …
```

문구가 전부 이미지에 구워져 있습니다. 그래서:

- **검색에 안 걸립니다.** 네이버·구글이 읽을 글이 219자뿐입니다
- 화면낭독기가 못 읽습니다
- 휴대폰에서 확대해야 읽힙니다
- 문구 한 줄 고치려면 디자이너를 불러야 합니다

우리 홈페이지는 반대입니다 — 글은 글로 두고, 그림은 직접 그린 SVG 라
**고치는 데 몇 분**입니다. 이건 따라가면 안 되는 쪽입니다.

## teefitlab.com (2026-08-12 참고)

첫 홈페이지를 짤 때 본 곳입니다. **수가표 요청 폼이 전환 장치**라는
것을 여기서 배웠습니다 ([[ds-flow-homepage]]).

★ 그 회사 **이용약관은 반면교사**입니다 — 다른 약관을 가져와 다 지우지
  못한 문서라 조항이 서로 안 맞습니다. 베끼면 결함까지 물려받습니다.
  대조표: 저장소의 `docs/DS-Flow-처리방침-참고대조.md`
