Den Flow 조직 구조는 **통합(B) 모델**로 확정됐습니다 (사용자가 A/B 중 B 선택).

- 자사 기공소를 **별도 조직으로 만들지 않습니다.** 디자인센터가 기공 권한을 함께 갖습니다.
- **자사 제작 판별** — 주문의 `lab_org_id`가 디자인센터 자신을 가리키면 자사 제작입니다. 이때는 지급이 발생하지 않습니다.
- **외부 기공소**만 `DL-001` 같은 별도 조직으로 만듭니다.
- 조직 코드 규칙 — `DC-001`(치과) / `DD-001`(디자인센터) / `DL-001`(기공소), 세 자리 순번.
- 번호 형식 — 주문 `ORD-260806-001`, 청구 `INV-202608-001`.
- `organizations`에서 `plan_id`는 뺐고 `ceo_name`을 넣었습니다(청구서에 대표자명이 필요).

**Why:** 설계서 §4.7은 원래 자사 기공을 지급 대상에서 빼는 구조인데, 조직을 나누면 원가가 따로 잡히는 대신 관리가 늘어납니다. 사용자가 단순함을 택했습니다.

**How to apply:** 기공소 배정 드롭다운은 `partnerships(design_lab)`만 읽으면 안 됩니다. **디자인센터 자신도 배정 후보**여야 자사 제작이 표현됩니다. 정산에서는 `lab_org_id = design_org_id`인 건을 지급 명세에서 제외합니다.
