## 파일

```

같은 폴더에 _1 _2 사본이 있고 내용은 같습니다
```

★ `.hwp` 는 바탕화면에 있다가 없어졌습니다. **한글 파일은 그냥 못 읽습니다** —
  OLE 컨테이너라 `zlib.decompress(raw[offset:], -15)` 로 BodyText 를 풀고
  UTF-16LE 로 읽어야 합니다. 미리보기(PrvText)만 따로 들어 있기도 합니다.
  **원본 마크다운을 찾는 편이 훨씬 빠릅니다** — 실제로 Downloads 에 있었습니다.

## ★ 지시서와 다르게 간 것 둘 — 사용자가 직접 뒤집었습니다

**① 「다른 기공소 배정 금지」 → 유지합니다.**
지시서는 배정·재배정 기능을 '절대 하지 말 것' 으로 적었습니다(의료기사법
제11조의3 — 의뢰서 발행 주체가 흐려진다는 이유). 그런데 사용자가
*"장비 구매 초반에만 외주를 돌릴 거고 결국엔 안 쓸 거야. 당장은 필요해"*
라고 정했습니다. **기능을 그대로 둡니다.**

**② 「환자정보 2년 자동삭제 + 테이블 분리」 → 안 합니다.**
*"치과는 삭제가 되면 안 될 것 같아. 나중에 소통할 때 그 기록으로
소통을 해야 할 거 같거든"* → **주문 기록은 영구.**
분리하려던 이유가 2년 삭제였으므로 `order_patients` 분리도 사라집니다
([[ds-flow-retention]]).

## 아직 안 한 것

**§3-3 매니페스트 + 「업로드중」 주문 상태** — 파일이 덜 올라간 주문이
기공소 작업목록에 뜨는 것을 막는 일. 매니페스트(올리기 전 줄 만들기)는
이미 있고, **주문 상태를 새로 만드는 일**이 남았습니다. 상태 전이 규칙을
건드려서 주문목록 필터·기공소 화면·통계·정산까지 영향이 넓습니다.

**§4 자동 삭제 잡** — 지금은 사람이 눌러야 돕니다. 센터만 자동으로.

**§5 약관·처리방침 문구** — "180일 보관 후 파기" 가 아직 어디에도 없습니다.

## 법률 주의

지시서 스스로 밝혀 뒀습니다 — 변호사 자문이 아니고, 스캔 데이터가 의료법
보존의무 대상이 아니라는 판단은 하급심 판례에 기댄 것입니다. 확정이
필요하면 보건복지부 유권해석이나 의료 전문 변호사 자문.
