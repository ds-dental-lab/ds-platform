# 쉐이드 포토 (진료실 모바일)

명세: `Desktop/SPEC_shade-photo.md` · 시안: `denflow-project/prototype/
shade-photo-prototype.html` (zip 안. 코드는 없고 지시서·명세·시안·로고
넷뿐인 출발 꾸러미) · 브랜드 규칙은 Desktop 의 CLAUDE.md.

**만든 이유** — 치과는 폰으로 찍어 카톡으로 보냅니다. ① 카톡이 눌러서
색이 왜곡되고(쉐이드 판별에 치명적) ② 대화방에 여러 환자가 섞이고
③ 나중에 그 환자 사진을 못 찾습니다. 답은 **사진이 처음부터 그 주문에
붙게** 하는 것 — 분류할 일이 아예 없어집니다.

★ **별도 프로젝트가 아니라 `ds-platform` 안에** 붙였습니다
  (사용자 결정 2026-08-21). 주문·계정·알림·저장소가 이미 다 있습니다.

## 주소

| | |
|---|---|
| `/m` | 오늘 의뢰 목록 (최근 7일, 날짜 묶음, 상태 칩) |
| `/m/[orderId]` | 케이스 상세 → 쉐이드 촬영 → 첨부 완료 |
| `/m/unsorted` | 미분류함 (묶음 목록) |
| `/m/unsorted/[sessionId]` | 어느 의뢰서에 붙일까 |
| `/playground/shade` | 다섯 화면 시연 (로그인 없이) |

`(mobile)` 라우트 그룹 — **SectorShell 을 안 씁니다.** 사이드바 200px 와
상단바가 진료실 폰에서는 화면의 절반입니다.

## 사용자가 정한 것 둘 (2026-08-21)

★★ **쉐이드 사진만 원본.** 다른 사진은 2026-08-14 결정대로 1600px·WebP
  로 줄이는데, 쉐이드는 **카톡의 압축을 피하려고** 만드는 기능입니다 —
  우리가 또 줄이면 만드는 이유가 없어집니다.
  `uploadOrderFiles(..., { compress: false })` · canvas `toBlob` 화질 1.0.
  저장소는 180일에 65GB 어름(스캔의 10분의 1).

★ **로그인은 지금 계정 그대로.** 명세의 '치과 공용계정 + 스태프 PIN' 은
  안 만들었습니다 — 인증을 하나 더 두면 기존 권한 규칙과 섞이는 자리가
  생깁니다.

## 미분류 (S5·S6)

`unsorted_photos` 새 표 — `order_files` 는 주문 없이 한 줄도 못 만듭니다.
`order_id` 를 비울 수 있게 바꾸는 길도 있지만 그 칸은 정책·조회·트리거
수십 군데가 '있다' 고 믿고 씁니다.

- 경로 `unsorted/{치과조직id}/{묶음id}/…` — 기존 정책은 두 번째 칸을
  주문으로 읽어 `can_access_order` 가 false 를 주므로 안 부딪힙니다
- 붙일 때 **옮깁니다**(move). 복사하면 미분류함에 남아 또 붙입니다.
  줄을 못 만들면 되돌려 놓습니다
- 매칭은 **묶음 단위**. 장마다 고르게 하면 그게 곧 카톡입니다
- 어느 단계에서도 안 막습니다. 한 번 막히면 다음부터 카톡을 씁니다

### ★★ move 는 이름 바꾸기(update)입니다

읽기·쓰기·지우기만 열어 뒀더니 `NoSuchKey / Object not found` 로
떨어졌습니다. **정책을 읽어서는 안 보이고**, 진짜 계정으로 옮겨 보고서야
알았습니다. `unsorted photos move` (for update) 를 따로 뒀습니다.
옮기기는 떠나는 자리(이 정책)와 닿는 자리(`order files replace`)가
둘 다 통과해야 합니다.

## 확인한 것 (진짜 계정)

미분류 올리기 ✓ / 기공소는 미분류함도 그 사진도 **못 봄** ✓ /
주문으로 옮기기 ✓ / 붙인 뒤 기공소가 **받음** ✓ (쉐이드라 맞습니다) /
그래도 스캔 원본은 여전히 막힘 ✓ ([[ds-flow-lab-sees-patient-name]])

## ★★ 만들다 잡은 버그

**날짜 묶음이 `toISOString()`(UTC)을 썼습니다.** 한국 시각 오전 9시
이전 주문이 전부 '어제' 로 떨어졌습니다 — 오전 8:50 주문이 '어제 8월
21일' 이라는 말이 안 되는 묶음이 됐습니다. **진료실은 아침 일찍
시작합니다.** 폰의 날짜로 셉니다.
