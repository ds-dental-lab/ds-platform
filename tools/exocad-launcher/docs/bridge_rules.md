브릿지 커넥터 규칙 (덴트버드 Crown 웹 화면)

이 문서가 규칙의 원본입니다. 코드(dentbird_params.py, 밤 실행 batch_review.py)는 이 문서를 따릅니다.
규칙을 바꾸면 이 문서를 먼저 고치고, 근거 케이스를 bridge_cases.md 에 한 줄 보탭니다.
처음 작성 2026-11-03. 근거: 사용자가 눈으로 합격 판정한 케이스 4건(아래 표).


1. 합격 기준

합격은 덴트버드가 보여 주는 숫자(약함/최적/크기 초과)가 아니라 사용자의 눈입니다.
사용자가 보는 것은 셋입니다.
- 분리감: 두 크라운 사이 교합면 쪽 외개(V 홈)가 살아 있어야 합니다.
- 커넥터가 교합면 쪽에 붙어 있으면 안 됩니다.
- 크라운 모양이 뭉개지면 안 됩니다(인접 거리 −0.5 같은 큰 값은 모양을 망칩니다).
덴트버드가 '최적' 이라던 원형 4×4 가 탈락한 적이 있습니다(상악 16-17).


2. 덴트버드 화면이 실제로 하는 일 (실측)

- 인접 거리(교합 및 인접 조정 → 거리 → 인접 거리, 모양 유지)는 마지막에 적용한 유닛의 값이
  그 유닛 양쪽 틈에 다 걸립니다. 나중에 넣은 값이 앞의 값을 덮어씁니다.
- + (연결 모드)는 두 크라운 바깥면이 닿는 만큼만 붙입니다. 면적 글자는 그 닿는 면적입니다.
- + 를 쓸 수 있는지는 화면 상태 connectProcess.mergeModePossible(접합별 true/false)이 정합니다.
  커넥터 패널 React props 에서 읽힙니다.
- 겹침이 너무 크면 + 가 잠깁니다. 덜 닿아서 잠기는 것이 아닙니다.
  상악 16-17 은 −0.08 까지 열리고 −0.10 부터 잠겼습니다. 하악 34-36 은 −0.30 에서도 열렸습니다.
- + 면적은 겹침에 비례하지 않습니다. 상악 25-27 은 −0.10 이 최대였고 −0.20 에서 줄었습니다.
- 원형 커넥터의 면적 글자는 실제 목보다 작게 나옵니다(원형 4×4 '약함 2.6' 이 내보낸 파일에서 목 단면 12.0mm²).
  + 의 작은 숫자는 실제로 끊길 수 있다는 신호입니다(+ '약함 1.6' 이 내보낸 파일에서 목 0).
- 같은 스캔이라도 다시 생성하면 크라운 모양이 조금씩 달라져 면적 숫자가 달라집니다.
  그래서 규칙은 고정 숫자가 아니라 화면을 읽어 판단하는 방식이어야 합니다.
- 인접 거리 입력은 화면 코드로 넣어도 키보드와 같은 결과가 납니다(입력칸에 값 넣기, Enter, 모양 유지 단추).


3. 규칙 (순서대로)

1) 분석이 이웃한 크라운 둘을 따로 잡으면 Smart order 에서 링크 단추를 누르고 '적용' 해 브릿지로 묶습니다.
2) 생성합니다.
3) 자연치에 닿는 유닛을 인접 거리 −0.02, 모양 유지로 먼저 맞춥니다.
4) 안쪽 유닛(폰틱, 또는 자연치가 없는 쪽 끝)을 −0.05 부터 0.05 씩 내리며 매번 + 가능 여부와 + 면적을 읽습니다.
   + 가 잠기거나 면적이 줄면 한 단계 앞 값으로 돌아갑니다. 그 값이 고른 값입니다.
5) 양쪽 바깥이 모두 자연치인 2유닛(안쪽 유닛 없음)은 나중에 넣는 값이 자연치 접촉에도 걸리므로 −0.10 에서 멈춥니다
   (2026-11-02 사용자 결정 '맞컨택은 −0.1').
6) + 로 합칩니다.
7) 교합면 쪽 접촉이 부족하면 '이동 및 변형' 의 근심(이웃 쪽) 옆 손잡이로 그 크라운을 이웃 쪽으로 조금 늘립니다.
   + 가 열린 채 접촉이 위로 올라옵니다. 숫자 입력이 없고 마우스 손잡이뿐이라 아직 자동화하지 않았습니다.
8) 폰틱이 옆 지대치 프렙 안쪽(마진선 안)과 겹쳐 + 면적이 0 근처에서 안 오르면 원형 4×4 를 쓰고,
   치아 초점 보기에서 커넥터 중심을 약 1mm 잇몸 쪽으로 끌어내립니다.
9) 내보낸 뒤에는 프렙 침범 밀어내기를 항상 합니다(바깥 모양은 안 바뀜).

하지 말 것
- 인접 거리 −0.5 처럼 큰 값을 처음부터 넣지 않습니다.
- 자연치 쪽 유닛을 안쪽 유닛보다 나중에 만지지 않습니다.
- 회귀 시험을 기존 합격 케이스에서 하지 않습니다. Smart order 로 돌아가는 순간 저장된 합격 디자인이 처음 상태로 바뀝니다.
- '이동 및 변형' 의 회전 아이콘을 끌지 않습니다. 회전이 아니라 이동으로 먹혀 크라운이 프렙에서 벗어납니다.


4. 아직 모르는 것

- 아래(마진 쪽) 연결을 더 채우는 방법(하악 34-35 요청). 후보: 외형 → 조각 → 더하기 브러시.
- 전치부(덴트버드 기준 9mm²), 4유닛 이상, 대합치 없음, 임플란트, 에그쉘.
- + 가 잠기는 정확한 조건(가설: 겹침이 마진 근처까지 내려가면 잠김).
